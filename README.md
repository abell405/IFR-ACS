# IFR ACS Study Guide

A searchable study guide for the FAA Instrument Rating – Airplane ACS (FAA-S-ACS-8C), Areas of Operation I–VIII. Every Knowledge and Risk Management element is listed by its ACS code, with the Skill elements and checkride tolerances for each task, scenario questions at the end of each task, and a full mock oral.

**Live site:** https://abell405.github.io/IFR-ACS/

Companion guide: [PPL ACS Study Guide](https://abell405.github.io/PPL-ACS/)

## Using it

- Pick an Area, task, or element code from the sidebar (the "Tasks" button on a phone).
- Search for a reg number, ACS code, or topic (e.g. `91.185`, `RAIM`, `IR.III.B`) to filter and highlight matches.
- Tap a scenario or decode drill to reveal the answer.
- The Reference section covers topics the instrument ACS tests without a task of its own: airspace, aeromedical factors and decision-making, performance, IFR altitudes, formulas, mnemonics, and regulations.

Scenarios are set around Southwest Florida; altitudes and minimums in them are made up for practice. Aircraft numbers are for the Piper Pilot 100i. Verify against the current ACS, 14 CFR, AIM, charts, and the POH for the airplane you fly.
